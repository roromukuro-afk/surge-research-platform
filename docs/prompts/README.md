# docs/prompts

プロンプト原文の保管場所。方針は [../prompt-versioning-policy.md](../prompt-versioning-policy.md)。

## ファイル

| ファイル | 状態 |
|---|---|
| `short-surge-v5.1.md` | **未受領**（ユーザーから原文を受け取り次第、無加工で保存する） |
| `MANIFEST.md` | 各原文ファイルの SHA-256。v5.1 保存時に作成 |
| `addenda/` | v5.1 以後の確定追加仕様（v5.1 原文より優先） |

## 禁止事項

- 原文ファイルの要約・短縮・リライト・条件削除・配点変更・整形変更
- 旧版の削除
- 追加仕様を原文ファイルに直接書き込むこと（必ず `addenda/` に別ファイル）
