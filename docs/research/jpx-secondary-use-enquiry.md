# D-102: JPX 統計ファイルの二次利用に関する照会文（送信用ドラフト）

状態: **ユーザー送信待ち** — 2026-09-17
関連: [D-102](../unresolved-decisions.md)、[news-source-licence-review.md](news-source-licence-review.md)

## なぜ書面照会が要るのか

JPX の統計ファイル（日次の株価・出来高等）は公開されているが、利用規約は
**「二次利用」を定義しないまま禁止している**。robots.txt は巡回を許可しており、
「取りに行ってよいか」と「持っていてよいか」は別の問いなので（D-124）、
公開文書だけでは決着しない。

そして、これは **JP の当日 EOD 価格を 0 円で得る唯一の経路**である。
可否がここで決まるので、推測で進めない。

## 照会の書き方

**「使っていいですか」と聞かない。** 曖昧な質問には曖昧な答えしか返らず、
返ってきた答えを後から自分に都合よく読む余地が残る。
実際にやること・やらないことを列挙して、その範囲について可否を尋ねる。

## 本文（このまま送れる）

```
東京証券取引所
株式部 データサービス室 御中

貴所ウェブサイトで公開されている統計情報の利用について、
可否をご教示いただきたく照会いたします。

【照会者】
個人1名です。法人・団体ではありません。
以下の利用はすべて、この個人1名の私的な投資判断および
その精度検証のための研究に限られます。

【予定している利用】
1. 貴所ウェブサイトで公開されている統計ファイル（日次の株価・
   出来高等）を、自動的に定期取得すること。
2. 取得したファイルおよびその数値を、当人のみがアクセスできる
   非公開のデータベースに保存すること。
3. 保存した OHLCV を数値解析し、特徴量を生成すること。
4. その特徴量を用いて、自動的な銘柄スクリーニングを行うこと。
5. 過去の自分の投資判断が正しかったかを、保存した価格系列に
   照らして事後検証すること。

【行わないこと】
1. 取得した生データ（ファイルそのもの、およびその複製）を
   第三者へ提供しないこと。
2. 生データを公開・再配布しないこと。
3. 生データまたはその実質的な複製を含む情報を、有償無償を
   問わず販売・提供しないこと。
4. 第三者向けのサービス・アプリケーション・情報提供の
   基礎データとして用いないこと。
5. 貴所の情報であることを偽って表示しないこと。

【照会事項】
上記【予定している利用】の 1 から 5 は、貴所の利用条件上
許容されるでしょうか。

許容されない項目がある場合は、どの項目が、どの規定に
抵触するかをご教示いただけますと幸いです。

また、許容される場合であっても、取得頻度の上限、出典表示の
方法、保存期間など、遵守すべき条件がございましたら
併せてご教示ください。

お忙しいところ恐縮ですが、よろしくお願い申し上げます。

（氏名）
（連絡先）
```

## 回答の扱い

| 回答 | 次の行動 |
|---|---|
| 1〜5 すべて可 | JP EOD Provider adapter を接続する。回答文面を `docs/research/` に保存し、`market.provider_licenses` へ `ALLOWED` として根拠付きで記録する |
| 一部不可 | 不可の項目だけを外して再設計する。**「たぶん大丈夫」で進めない** |
| 不可 | `market.provider_licenses` に `PROHIBITED` として理由付きで記録し、JP EOD の別経路を探す |
| 回答なし | **沈黙は同意ではない**（quad-state の `NOT_SPECIFIED` / `UNKNOWN`）。取得を開始しない |

## この回答を待つ間に止めないこと

D-102 は JP の EOD 価格だけを止める。Yanoshin TDnet による JP 適時開示の
Discovery は live verified 済みで、価格が無い間も material collection は
継続してよい（Phase 12 の readiness command が JP を `PARTIAL_LIVE` と
判定するのはこの状態を指す）。
